Bina · refined

A caring dental scan, in the family pocket.

This UI kit is a high-fidelity React recreation of the Bina mobile app under the refined design system. Tap a screen on the right to navigate — every chip, button, and avatar is composed from the tokens in colors_and_type.css.

Source for these recreations: lib/pages/ in the BinaApp Flutter codebase.
